help_outline 1. Claude Codeってなに？

Claude Codeは、AIアシスタント「Claude」がターミナル（黒い画面）の中で直接動くツールです。普通のチャットとは違い、パソコンのファイルを読んだり、書いたり、プログラムを実行したりすることができます。

できること

description

ファイルを作る・編集する

HTMLやPDFなどのファイルを話しかけるだけで作れる

bug_report

バグを直す

エラーが出たときに原因を調べて修正してくれる

chat

コードを説明する

難しいプログラムを日本語でわかりやすく説明

web

Webサイトを作る

HTMLやCSSで見た目のきれいなサイトを作成

slideshow

スライドを作る

PowerPointのスライドを自動で作成してくれる

smart_toy

自動化ツールを作る

繰り返し作業を自動でやってくれるツールを作成

extension 7. 便利な機能

MCP（外部ツール連携）

MCPとは「Model Context Protocol」の略で、Claude Codeを外部のツールと繋げる仕組みです。例えば：

  • ブラウザを操作してWebページを確認する
  • Googleスプレッドシートのデータを読み書きする
  • GitHubのコードを参照する

スキル（/skill-name）

よく使う作業をワンコマンドで実行できる「スキル」という機能があります。例えば /pptx と打つだけでスライド作成モードになります。

メモリ機能

api 8. Claude API の使い方

APIキーの取得方法

  1. Anthropicのコンソール（console.anthropic.com）にアクセス
  2. アカウントを作成してログイン
  3. 「API Keys」メニューから新しいキーを作成
  4. キーをコピーして安全な場所に保存

環境変数への設定方法

# .envファイルに記載する ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxx

基本的なAPIリクエスト例（Python）

import anthropic client = anthropic.Anthropic() message = client.messages.create( model="claude-sonnet-4-6", max_tokens=1024, messages=[ {"role": "user", "content": "こんにちは！"} ] ) print(message.content)

モデルの選び方

最高性能

Opus 4.7

複雑な問題や高度な分析に。処理は少し時間がかかる

おすすめ

Sonnet 4.6

速さと性能のバランスが良い。通常の開発に最適

高速・軽量

Haiku 4.5

シンプルな処理に。速くて安価

料金の考え方

APIは使った量だけ料金が発生します。「トークン」という単位で計算され、日本語1文字≒1〜2トークンが目安です。

節約のコツ：必要以上に長いメッセージを送らず、用件を簡潔に伝えると料金を抑えられます。

settings 9. 設定・カスタマイズ

settings.json の基本設定

Claude Codeの動作は settings.json というファイルで細かく設定できます。

{ "theme": "dark", // 画面のテーマ（dark/light） "language": "ja" // 使用言語 }

CLAUDE.md でプロジェクトのルールを伝える

プロジェクトのフォルダに CLAUDE.md というファイルを置くと、そのフォルダで作業するときのルールをClaude Codeに伝えられます。

# CLAUDE.md の例 このプロジェクトは特別支援学校の教材を作るためのものです。 - 説明は平易な日本語で書いてください - 専門用語は避けてください - 文字は大きめにしてください

権限管理・フック

特定のコマンドを自動的に許可したり、ある操作の前後に自動実行する処理（フック）を設定できます。

注意：設定ファイルを変更するときは、元の内容をバックアップしてから行うことをおすすめします。

lightbulb 10. うまく使うコツ・Tips

効果的なプロンプトの書き方

具体的に伝える
❌「直して」
✅「15行目でエラーが出ています。TypeError を直してください」
役割を伝える
✅「あなたは特別支援学校の先生のアシスタントです。子どもにわかりやすく説明してください」
段階的に作る
一度にすべてを頼まず、まず最小限のものを作って、少しずつ追加していくと成功しやすい

うまくいかないときの対処法

困ったこと対処法
思った通りに作ってくれない「違います。〇〇のようにしてください」と具体的に言い直す
エラーが直らない「別の方法で直してください」と頼む
動作が遅い・止まったCtrl+C で中断して、もう一度頼む
会話が長くなりすぎた/clear でリセットして最初から頼む

よくある失敗パターン

  • 一度に何でも頼みすぎる → 少しずつ確認しながら進める
  • 「なんとなく」で頼む → 誰が使うか・何のためかを伝える
  • エラーを無視する → エラーメッセージをそのままコピーして貼り付ける
最大のコツ：うまくいかなくても大丈夫！Claude Codeは何度でも付き合ってくれます。「もう一度やり直して」「こうしてほしい」と遠慮なく伝えましょう。
